# Swiggy Clone — Frontend

A frontend-only website inspired by Swiggy, built to practice HTML, CSS, and JavaScript by recreating elements of a food delivery and grocery shopping interface.

## Features

- Swiggy-inspired homepage design
- Navigation bar and hero section
- Location selector and restaurant search interface
- Food delivery, Instamart, and Dineout promotional sections
- Grocery category sections with images
- JavaScript-based rendering of page content

*Note: Verify each feature against the current implementation before treating this list as final.*

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome icons

## Project Structure

- `SwiggyClone.html` — Main webpage
- `style.css` — Styling and layout
- `script.js` — JavaScript functionality
- `image1.avif` — Image asset

## Run Locally

1. Clone or download this repository.
2. Open `SwiggyClone.html` in your browser.
3. Ensure you have an internet connection if the page uses externally hosted images, fonts, or icons.

## Project Scope

This is an educational frontend clone inspired by Swiggy. It is not affiliated with the official Swiggy platform and does not provide real food ordering, payment processing, or backend services.
